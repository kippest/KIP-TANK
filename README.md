# 坦克大战 · Tank Battle

一个使用纯 HTML5 Canvas + JavaScript 编写的经典《坦克大战》（Battle City）小游戏，无需任何依赖，双击 `index.html` 即可在浏览器中游玩。

## 🎮 玩法

- 操控黄色坦克，消灭不断出现的敌方坦克，并保护你的基地（鹰徽）。
- 每关共 **20** 个敌人，全部消灭即可过关。
- 敌人共有 4 种：普通、快速、速射、装甲（需两发炮弹）。
- 敌人被消灭后可能掉落道具：
  - ⭐ 火力增强（+500 分）
  - 🛡️ 护盾（短时间内无敌）
  - 💣 全灭当前场上敌人
  - ❤️ 生命 +1

## 🕹️ 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始游戏 |

## 🧱 地形

| 地形 | 说明 |
| ---- | ---- |
| 🧱 砖墙 | 可被炮弹摧毁 |
| ⬜ 钢墙 | 不可摧毁（会挡住炮弹） |
| 🌊 水域 | 坦克无法通过，炮弹可以越过 |
| 🌳 树林 | 坦克可躲藏其中（遮挡视线） |
| 🦅 基地 | 被摧毁则游戏结束 |

## 🚀 运行

直接打开 `index.html`，或在任意静态服务器下访问：

```bash
# 例如使用 Python
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> 提示：由于音效使用 Web Audio API，若浏览器拦截自动播放，首次点击「开始游戏」后即可正常发声。
